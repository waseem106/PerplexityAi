# PerplexityAi

A Next.js application project exploring an AI-search-style interface.

> Status: Development project. Features and deployment have not been independently verified.

## Technology

- Next.js 15, React 19 and TypeScript
- Tailwind CSS 4, Radix UI and Lucide
- Clerk integration dependency
- MongoDB and Mongoose

## Run locally

```bash
npm install
npm run dev
```

Visit http://localhost:3000. For production builds run `npm run build` and `npm start`.

Some integrations may require environment variables. Keep API keys and credentials out of Git.
